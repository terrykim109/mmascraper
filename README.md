# mmascraper

Mixed Martial Arts (MMA), arguably the fastest-growing sport of the past decade, has evolved from a niche interest into a mainstream fixture. As a longtime fan of the sport, I wanted to use Python to build a simple web application that makes UFC data easier to browse and explore.

The application scrapes UFC statistics and presents them through a Flask-based website. Users can view a list of fighters, filter and sort them by key performance metrics, and click into individual profiles to see basic stats and fight histories. The app also includes event pages that display fight card results and outcomes.
